# Support

Craft Protocol is community-maintained open-source software provided without warranty.

- **Questions and design discussion:** use [GitHub Discussions](https://github.com/razumv/craft-protocol/discussions).
- **Reproducible bugs and scoped features:** use the repository Issue templates.
- **Security vulnerabilities or sensitive-data exposure:** use a [private security advisory](https://github.com/razumv/craft-protocol/security/advisories/new), not a public issue.

Before asking for help:

1. read `README.md` and `docs/CURRENT-DEFAULTS.md`;
2. run `./install.sh` in dry-run mode;
3. run `./tools/generate-manifest.sh --check`;
4. run the regression suite;
5. sanitize all logs, paths, IDs, and fixtures.

Maintainers and contributors may answer when available; no response-time or production-support SLA is provided.
